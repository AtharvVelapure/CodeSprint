# Stability fixes - 2026-09-29

- Kept production-safe global exception responses while logging unexpected exceptions server-side.
- Fixed assessment-host verification DTO creation with `spring.jpa.open-in-view=false` by keeping lazy `User` access inside a service transaction.
- Applied transactions to assessment verification create/read/admin review operations.
- Fixed contest result and problem-result lazy association access by keeping result assembly inside transactions.
- Mail credentials are no longer stored as plaintext defaults; use `MAIL_USERNAME` and `MAIL_PASSWORD`.
- JWT supports `JWT_SECRET` with a local-development fallback. Replace it for deployed environments.
- Database password supports `DB_PASSWORD`; the existing local fallback is retained only so the current local database setup can start without extra configuration.
